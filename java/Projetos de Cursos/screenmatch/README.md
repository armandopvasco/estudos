# Java: trabalhando com lambdas, streams e Spring Framework
Projeto desenvolvido no primeiro curso da formação Avançando com Java da Alura.

Dado início ao projeto que utiliza a OMDb API, para consultar dados de séries de TV.

## 🔨 Objetivos do projeto

- Desenvolver o projeto Screenmatch;
- Modelar as abstrações da aplicação através de classes, records e métodos;
- Utilização de lambdas, streams e iniciação ao Spring Framework;
- Controle de dependências com Maven;
