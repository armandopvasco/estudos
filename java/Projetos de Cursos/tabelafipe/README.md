# Java: Desafio Comsumo de API
Projeto desenvolvido no primeiro curso da formação Avançando com Java da Alura.

Dado início ao projeto de desafio, utilizando-se de uma API que contém dados da tabela FIPE:
https://deividfortuna.github.io/fipe/

## 🔨 Objetivos do projeto

- Desenvolver o projeto tabelafipe;
- Modelar as abstrações da aplicação através de classes, records e métodos;
- Revisar a utilização de lambdas, streams e iniciação ao Spring Framework;
- Controle de dependências com Maven;
